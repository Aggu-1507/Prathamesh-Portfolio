# Prathamesh-Portfolio

Source for my portfolio site: https://aggu-1507.github.io/Prathamesh-Portfolio/

A plain static site with no build step.

- `index.html`: page content
- `styles.css`: layout and theme
- `script.js`: the typing line, the mobile menu and the figure viewer
- `*.png`, `*.jpg`: project figures
- `Prathamesh_V_Narayan_Resume.pdf`: the resume linked from the page
- `Prathamesh_CV.pdf`: the cover letter linked from the contact section

GitHub Pages serves the `main` branch root, so every commit updates the site.
To preview locally, open `index.html` in a browser.
